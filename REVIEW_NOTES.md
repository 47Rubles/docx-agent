# Проверка требований — 22 октября 2026

## Исправлено
- AST: `metadata`, `runs`, `display_mode`, `critical`, размеры объединений; автоматическая загрузка прежнего JSON.
- Компилятор: оставлены стили шаблона; ошибки LaTeX не прерывают сборку; опционально включается `trackRevisions`.
- Таблицы: поддержаны `col_span`, `row_span`, выравнивание, ширины, повторение заголовков.
- Врезка: корректная толщина границы 24/8 = 3 pt.
- Агент: 2 повторных запроса для исправления JSON, расширенный контракт интервьюера.

- `python -m pytest -q`: 8 тестов пройдены.

- `.dotx` как источник оформления; используются `.docx` шаблоны.
- Полнота формул Microsoft XSLT, строгая проверка XSD ECMA-376 и гарантированный performance SLA.
- Реальный Anthropic API и end-to-end проверка сетевого контура.
